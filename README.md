# Política de privacidad de MyTreino

Esta página existe para un solo fin: Google Play exige que la política de
privacidad de una app esté publicada en una URL que abra sin iniciar sesión.

**Se publica en:** https://tomich78.github.io/mytreino-privacidad/

## Si hay que cambiarla

El original vive con el código de la app, en `movil/play/privacidad.md`, y
`privacidad.html` se genera a partir de ese texto. Este repositorio tiene una
copia en `index.html`.

Así que al cambiar algo hay que tocar las dos cosas: el original junto a la
app, y esta copia. Y si lo que cambió es **qué datos guarda la app**, también
hay que actualizar el formulario de seguridad de los datos en Play Console,
porque Google compara lo declarado con lo que la app hace.

El repositorio es público porque GitHub Pages lo exige en las cuentas
gratuitas. No contiene nada del código de la app.
